# express-mongo-auth

API REST con Express y MongoDB Atlas, desplegada en Render con CI/CD mediante GitHub Actions.

## Endpoints

- `GET /api/users`
- `GET /api/users/:id`
- `POST /api/users`
- `PUT /api/users/:id`
- `DELETE /api/users/:id`

## Uso local

1. Copiar `.env.example` a `.env` y completar las credenciales.
2. `npm install`
3. `npm run dev`
